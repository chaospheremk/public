  C. On the work computer — start a second PowerShell window for live tailing (optional)

  10. In a second pwsh window, prime the tail script (it will start watching once the JSONL appears). Run this before
  kicking off the main run.

  while (-not (Get-ChildItem 'C:\AdPermAudit-Diag1' -Filter '*.jsonl' -ErrorAction SilentlyContinue)) {
      Start-Sleep -Seconds 1
  }
  $latest = Get-ChildItem 'C:\AdPermAudit-Diag1' -Filter '*.jsonl' |
            Sort-Object LastWriteTime -Descending | Select-Object -First 1

  Get-Content $latest.FullName -Wait -Tail 0 | ForEach-Object {
      $e = $_ | ConvertFrom-Json
      $mem = $e.data.memory
      if ($mem) {
          '{0}  {1,-8} {2,-22}  heap={3,7}MB  ws={4,7}MB  gen2={5,3}' -f `
              $e.timestamp, $e.phase, $e.event,
              $mem.managedHeapMB, $mem.workingSetMB, $mem.gen2Collections
      } else {
          '{0}  {1,-8} {2,-22}  {3}' -f $e.timestamp, $e.phase, $e.event, $e.message
      }
  }

  10. Watch for:
    - workingSetMB doubling between consecutive events
    - Gen2 count never advancing (means GC isn't reclaiming)
    - Long gaps with no events (process busy or stuck)
    - OS getting unresponsive / Task Manager Committed > Physical RAM → Ctrl+C the main run in the other window. Note
  the timestamp.

  11. Run this whole block as one paste. Don't change parameters unless you have a specific reason (and note the
  deviation if you do).

  $timestamp = Get-Date -Format 'yyyyMMdd-HHmmss'
  $params = @{
      OutputDirectory       = 'C:\AdPermAudit-Diag1'
      ThreadCount           = 2
      BatchSize             = 50
      PageSize              = 1000
      IncludeNamingContexts = @('Domain')

  $transcript = Join-Path $params.OutputDirectory "Diag1_$timestamp.transcript.txt"

  Write-Host '--- Pre-run baseline ---'
  Write-Host "Start:              $(Get-Date -Format 'o')"
  Write-Host "Process PID:        $PID"
  Write-Host "Process WS (MB):    $([Math]::Round((Get-Process -Id $PID).WorkingSet64 / 1MB, 1))"
  Write-Host "Available RAM (MB): $([Math]::Round((Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory / 1024,
  1))"

  $exitCode = 0
  try {
      .\scripts\Invoke-ADPermissionAnalysis.ps1 @params
      $exitCode = $LASTEXITCODE
  }
  catch {
      $exitCode = 1
      Write-Host "RUN THREW: $($_.Exception.Message)"
      Write-Host $_.ScriptStackTrace
  }
  finally {
      Write-Host '--- Post-run summary ---'
      Write-Host "End:                $(Get-Date -Format 'o')"
      Write-Host "Exit code:          $exitCode"
      Write-Host "Process WS (MB):    $([Math]::Round((Get-Process -Id $PID).WorkingSet64 / 1MB, 1))"
      Write-Host "Available RAM (MB): $([Math]::Round((Get-CimInstance Win32_OperatingSystem).FreePhysicalMemory / 1024,
   1))"
      Stop-Transcript | Out-Null
  }

  # Stash the timestamp for the post-run scripts below.
  $timestamp | Set-Content "C:\AdPermAudit-Diag1\last-run-timestamp.txt"

  E. On the work computer — post-run capture

  13. Run this block after the script exits (or after you confirm the process is dead).

  $timestamp = (Get-Content 'C:\AdPermAudit-Diag1\last-run-timestamp.txt').Trim()
  $jsonl = Join-Path 'C:\AdPermAudit-Diag1' "Diag1_$timestamp.jsonl"
  $summaryPath = Join-Path 'C:\AdPermAudit-Diag1' "Diag1_$timestamp.summary.txt"

  # Redirect everything below into the summary file AND echo to console.
  & {
      '--- JSONL summary ---'
      "Path:       $jsonl"
      "Size (KB):  $([Math]::Round((Get-Item $jsonl).Length / 1KB, 1))"
      "Line count: $((Get-Content $jsonl | Measure-Object -Line).Lines)"

      ''
      '--- Last 30 events ---'
      Get-Content $jsonl -Tail 30

      ''
      '--- Top 10 events by workingSetMB ---'
      Get-Content $jsonl |
          ForEach-Object { $_ | ConvertFrom-Json } |
          Where-Object { $_.data.memory } |
          ForEach-Object {
              [PSCustomObject]@{
                  timestamp = $_.timestamp
                  phase     = $_.phase
                  event     = $_.event
                  heapMB    = $_.data.memory.managedHeapMB
                  wsMB      = $_.data.memory.workingSetMB
                  privMB    = $_.data.memory.privateBytesMB
                  gen2      = $_.data.memory.gen2Collections
              }
          } |
          Sort-Object wsMB -Descending |
          Select-Object -First 10 |
          Format-Table -AutoSize | Out-String

      '--- Per-phase summary (PhaseEnd events) ---'
      Get-Content $jsonl |
          ForEach-Object { $_ | ConvertFrom-Json } |
          Where-Object { $_.event -eq 'PhaseEnd' } |
          ForEach-Object {
              [PSCustomObject]@{
                  phase     = $_.phase
                  elapsedMs = $_.data.elapsedMs
                  heapMB    = $_.data.memory.managedHeapMB
                  wsMB      = $_.data.memory.workingSetMB
                  gen2      = $_.data.memory.gen2Collections
              }
          } | Format-Table -AutoSize | Out-String

      '--- Drain event count + peak ---'
      $drains = Get-Content $jsonl |
          ForEach-Object { $_ | ConvertFrom-Json } |
          Where-Object { $_.event -eq 'MidEnumerationDrain' }
      "Total drain events: $($drains.Count)"
      if ($drains.Count -gt 0) {
          "Max drained per pass: $(($drains.data.drained | Measure-Object -Maximum).Maximum)"
          "Max wsMB at drain:    $(($drains.data.memory.workingSetMB | Measure-Object -Maximum).Maximum)"
      }

  } *>&1 | Tee-Object -FilePath $summaryPath
  14. If the process died unexpectedly (you observed it vanish from Task Manager, or the transcript ends with no

  $timestamp = (Get-Content 'C:\AdPermAudit-Diag1\last-run-timestamp.txt').Trim()

  F. On the work computer — sanitize

  15. Edit these three placeholder values in the next block before running. Don't run this with the placeholders
  unedited — the redaction won't catch anything.

  $timestamp = (Get-Content 'C:\AdPermAudit-Diag1\last-run-timestamp.txt').Trim()
  $src = Join-Path 'C:\AdPermAudit-Diag1' "Diag1_$timestamp.jsonl"
  $dst = $src -replace '\.jsonl$', '.sanitized.jsonl'

  # ===== FILL THESE IN BEFORE RUNNING =====
  $realDomain         = 'REPLACE-WITH-FQDN.example.com'   # e.g. corp.contoso.com
  $realServer         = 'REPLACE-WITH-DC.example.com'     # e.g. dc01.corp.contoso.com
  $realNetbiosDomain  = 'REPLACE-WITH-NETBIOS'            # e.g. CONTOSO
  # =========================================

  $ncRegex  = [regex]'DC=[^,"]+(?:,DC=[^,"]+)+'
  $sidRegex = [regex]'S-1-5-21-\d+-\d+-\d+(-\d+)?'

  Get-Content $src | ForEach-Object {
      $line = $_
      $line = $line -replace [regex]::Escape($realDomain), '<DOMAIN>'
      $line = $line -replace [regex]::Escape($realServer), '<SERVER>'
      $line = $line -replace [regex]::Escape($realNetbiosDomain), '<NETBIOS>'
      $line = $ncRegex.Replace($line, '<NC>')
      $line = $sidRegex.Replace($line, '<SID>')
      $line
  } | Set-Content $dst -Encoding utf8
  16. Verify sanitization worked. This should print nothing. If it prints lines, fix them before transferring.

  Select-String -Path $dst `
                -Pattern 'DC=[^,"<]+,DC=','S-1-5-21-\d',[regex]::Escape($realDomain) |
      Select-Object -First 10

  16. Also eyeball-check the sanitized file:

  } | Set-Content $transcriptSanitized -Encoding utf8
